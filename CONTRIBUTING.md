# Contributing to Ironclad

Thanks for considering a contribution. Ironclad is a portable set of
engineering standards for AI coding agents, and it holds itself to the
standards it ships.

## The one structural rule

`content/` is the single source of truth. Every rule lives in exactly one
canonical Markdown file there. The files under `adapters/` reference that
content; they do not duplicate it, except for the small cross-cutting
rules deliberately inlined for harnesses that cannot import at a global
scope. So:

- To change a rule, edit the file in `content/`.
- If a change affects routing or the inlined cross-cutting rules, update
  `content/task-routing.md` and all three adapter templates together, so
  the harnesses do not drift apart.
- Never edit an installed copy (under `~/.ironclad`, `~/.claude`, and so
  on). Those are generated by the installer.

## Content versus mechanism

Two kinds of contribution, with different review bars:

- Content (the Markdown standards) is judged on whether the guidance is
  correct, portable across stacks, and not specific to one project. Keep
  the reasoning that explains why a rule exists.
- Mechanism (the installer, the git hook, the `bin` command, the adapter
  structure) runs on a user's machine, so it must keep the tests passing
  and should add a test for new behavior.

## Commit messages

Commit messages follow Conventional Commits, in English, because the
version bump depends on them (see `content/commits.md`): `fix:` bumps the
patch, `feat:` the minor, and a `!` or a `BREAKING CHANGE:` footer the
major. A change that is none of these (docs, tests, CI, chores) uses the
matching type and does not bump the version.

## Running the tests

```bash
cd installer && npm test
```

```bash
bash scripts/test-hook.sh
```

The installer smoke test runs in CI on Linux, macOS, and Windows; the
hook test on Linux and macOS. A pull request should pass them before
review.

## Language

All content and output is in English, per `content/language.md`,
regardless of the language a contributor works in day to day.
